# Smileat Competitive Intelligence

Web estática por categorías. Cada página es autosuficiente (los estilos van dentro), así que se puede abrir cualquier `.html` sin más archivos. Mantén todos los archivos en la misma carpeta para que la navegación funcione.

## Páginas

- `index.html` — portada con las categorías y el resumen del periodo.
- `lanzamientos.html` — Lanzamientos y marcas propias.
- `campanas-eventos.html` — Campañas, comunicación y eventos.
- `promociones-retail.html` — Promociones y precios en retail.
- `regulacion-nutricion.html` — Regulación, nutrición y seguridad.
- `tendencias.html` — Tendencias de innovación.
- `redes-sociales.html` — Publicidad en redes sociales (próximamente).
- `medios.html` — Publicidad en medios (próximamente).

## Publicar en GitHub Pages

Sube los archivos a un repositorio y activa Pages (Settings → Pages → rama `main`, carpeta `/root`). La página de inicio es `index.html`.
